## How to add the next post

1. Drop a Markdown file in `_posts/` named `YYYY-MM-DD-slug.md`.
2. Front matter needs `title` and `date`; `description` and `tags` are optional.
3. `git push` — the GitHub Actions workflow rebuilds and deploys.

```yaml
---
title: "A real post"
date: 2026-06-01 10:00:00 +0530
description: "What this post is about, in one sentence."
tags: [research, time-series]
---
```
